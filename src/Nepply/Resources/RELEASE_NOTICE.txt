Nepply release candidate - please read before installing

This is a release candidate. Nepply is not code-signed yet, so Windows
SmartScreen may warn you. Continue only if you downloaded this file from the
official release page: https://github.com/minhquang0607/Nepply/releases
Never turn off Windows security features to install or run Nepply.

- Desktop icons: Nepply hides your Desktop icons only if you turn that option
  on. Files are never moved or deleted, and icons come back when Nepply exits.
  If they stay hidden, right-click the Desktop and choose
  View > Show desktop icons.
- System monitor: available readings depend on your hardware, drivers and
  permissions. CPU temperature is unavailable on many PCs. This installer does
  not install any driver.
- Privacy: no ads, analytics or automatic crash uploads.

Report a problem: https://github.com/minhquang0607/Nepply/issues

Nepply bản phát hành thử (RC) - vui lòng đọc trước khi cài

Đây là bản phát hành thử. Nepply chưa được ký số nên Windows SmartScreen có
thể cảnh báo. Chỉ tiếp tục nếu bạn tải file này từ trang phát hành chính thức:
https://github.com/minhquang0607/Nepply/releases
Không tắt các tính năng bảo mật của Windows để cài hoặc chạy Nepply.

- Biểu tượng Desktop: Nepply chỉ ẩn biểu tượng Desktop khi bạn bật tùy chọn
  này. File không bao giờ bị di chuyển hay xóa, và biểu tượng trở lại khi
  thoát Nepply. Nếu vẫn bị ẩn, nhấp chuột phải vào Desktop và chọn
  Xem > Hiển thị biểu tượng màn hình nền.
- Theo dõi hệ thống: số đo hiển thị được tùy phần cứng, driver và quyền truy
  cập. Nhiều máy không đọc được nhiệt độ CPU. Bộ cài này không cài driver nào.
- Quyền riêng tư: không quảng cáo, không analytics, không tự gửi báo cáo lỗi.
