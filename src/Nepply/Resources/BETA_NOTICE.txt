Hardware sensor availability depends on your hardware, driver and permissions.
CPU temperature is unavailable on many Intel/AMD PCs; motherboard temperature
and fan speed are not supported. This installer does not install PawnIO or any
other hardware monitoring driver. Do not disable Windows security protections
to obtain sensor readings.

Desktop icons: Nepply can hide the Windows Desktop icons only if you turn that
option on (first-run screen or Settings > Desktop). Files are never moved or
deleted; icons are restored when Nepply exits. If they stay hidden, right-click
the Desktop and choose View > Show desktop icons.
Biểu tượng Desktop: Nepply chỉ ẩn icon Desktop khi bạn bật tùy chọn này; file
không bị di chuyển hay xóa và icon được khôi phục khi thoát Nepply. Nếu icon
vẫn ẩn: chuột phải Desktop > Xem > Hiển thị biểu tượng màn hình nền.
