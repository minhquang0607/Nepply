Nepply release candidate - please read before installing

This is a release candidate. Nepply is not code-signed yet, so Windows SmartScreen may warn you. Continue only if you downloaded this file from the official release page: https://github.com/minhquang0607/Nepply/releases
Never turn off Windows security features to install or run Nepply.

- Desktop icons: Nepply hides your Desktop icons only if you turn that option on. Files are never moved or deleted, and icons come back when Nepply exits. If they stay hidden, right-click the Desktop and choose View > Show desktop icons.
- System monitor: available readings depend on your hardware, drivers and permissions. CPU temperature is unavailable on many PCs. This installer does not install any driver.
- Privacy: no ads, analytics or automatic crash uploads.

Report a problem: https://github.com/minhquang0607/Nepply/issues
